# KiraKira UI 设计语言与一致性审计报告

> **分析时间**：2026-01-20  
> **分析范围**：`lib/presentation/` 目录下 168 个 Dart 文件，重点关注主题、通用组件、主要页面  
> **分析方法**：静态扫描颜色值、圆角、间距、字体；对比两套设计系统；识别偏离规范值

---

## 1. 双设计系统并存现状

项目中**并存两套设计系统**，这是最大的一致性风险点：

| 维度 | **AppTheme** (主系统) | **GlassContainer** (毛玻璃系统) |
|------|----------------------|--------------------------------|
| 定义文件 | `lib/presentation/theme/app_theme.dart` (259行) | `lib/presentation/widgets/common/glass_container.dart` (147行) |
| 设计风格 | Material 3 + 自定义深色/浅色主题 | 毛玻璃拟物化 |
| 主色调 | `0xFF7C7BF0` (星蓝紫) | Blue: `0xFF79C7FF` / Graphite: `0xFFA8D8FF` |
| 背景色 | Dark: `0xFF0D1128` / Light: `0xFFEEEEF8` | Blue: `0xFF070B14` / Graphite: `0xFF101216` |
| 表面色 | Dark: `0xFF161B3A` / Light: `0xFFF5F5FF` | Blue: `0xFF0A0E1A` / Graphite: `0xFF14161C` |
| 卡片圆角 | **12** (CardTheme) / **20** (KiraCard) | **20** (cardRadius) / **22** (appBarRadius) / **24** (panelRadius) |
| 阴影风格 | 双层柔和阴影 (日间) / 高光边 (夜间) | 大范围低透明度阴影 + 高光边 |
| 字体系统 | Material 3 TextTheme 完整定义 | 无独立字体系统，依赖 Theme.of(context) |

**结论**：两套系统在颜色、圆角、阴影、透明度理念上**完全不同**，混用会导致视觉割裂。

## 4. 不一致清单 (按严重度)

### 4.1 🔴 严重 - 双系统并存导致视觉割裂

| 问题 | 影响范围 | 建议 |
|------|----------|------|
| **两套配色体系并存** | 全应用 | 统一到 AppTheme，GlassContainer 作为 AppTheme 的一个变体实现 |
| **两套圆角规范并存** | 卡片、对话框、输入框 | 统一为：小 8、中 12、大 16、超大 20、胶囊 30 |
| **两套阴影/高光规范** | 所有容器 | 统一语义：层级 1/2/3 对应阴影强度 |

### 4.2 🟠 中等 - 硬编码偏离设计系统

| 文件 | 行号 | 问题值 | 标准值 | 备注 |
|------|------|--------|--------|------|
| `chat_screen.dart` | 多处 | `BorderRadius.circular(16)` | 12 或 20 | 聊天气泡圆角不统一 |
| `message_bubble.dart` | 多处 | 硬编码颜色 | AppTheme 常量 | 应使用 Theme.of(context) |
| `webview_chat_stage.dart` | 内嵌 CSS | 独立 CSS 变量 | - | WebView 内部样式需同步 |
| `kira_components.dart` | 135 | `radius = 16` 默认 | 20 | GradientCard 与 KiraCard 不一致 |

### 4.3 🟡 轻微 - 间距/字体微小偏差

| 问题 | 位置示例 | 建议 |
|------|----------|------|
| `EdgeInsets.only(bottom: 10)` | `character_list_screen.dart` | 改为 8 或 12 |
| `fontSize: 13` | `message_content_widget.dart` | 改为 12 或 14 |
| `EdgeInsets.symmetric(horizontal: 28)` | `kira_components.dart` L101 | 改为 24 或 32 |
| `letterSpacing: 0.5` | 多处标题 | 统一到 0.3 或移除 |

## 6. 规范化建议

### 6.1 统一设计 Token (P0)

```dart
// lib/presentation/theme/design_tokens.dart (建议新建)
abstract class DesignTokens {
  // 圆角标准化
  static const double radiusXs = 4;
  static const double radiusSm = 8;
  static const double radiusMd = 12;  // 标准卡片、输入框、按钮
  static const double radiusLg = 16;  // 渐变卡片、对话框
  static const double radiusXl = 20;  // 主卡片
  static const double radiusFull = 30; // 胶囊、底栏

  // 间距标准化 (8pt 基准)
  static const double spaceXs = 4;
  static const double spaceSm = 8;
  static const double spaceMd = 16;
  static const double spaceLg = 24;
  static const double spaceXl = 32;
  static const double space2xl = 48;

  static const double fontSizeSm = 12;
  static const double fontSizeMd = 14;
  static const double fontSizeLg = 16;
  static const double fontSizeXl = 20;
  static const double fontSize2xl = 24;
  static const double fontSize3xl = 28;
}
```

### 6.2 合并 GlassContainer 到 AppTheme (P1)

```dart
// 在 AppTheme 中增加 glass 变体
```

## 7. 总结

| 维度 | 评分 | 说明 |
|------|------|------|
| **设计系统统一度** | ⭐⭐ | 双系统并存，视觉割裂风险高 |
| **Token 规范化** | ⭐⭐⭐ | AppTheme 内部较规范，但有硬编码分散 |
| **组件库复用性** | ⭐⭐⭐⭐ | kira_components 设计良好，但未覆盖全应用 |
| **跨平台一致性** | ⭐⭐⭐ | WebView 内嵌样式需同步 |
| **可维护性** | ⭐⭐ | 硬编码多，修改成本高 |

**核心建议**：**统一到单一设计系统** (AppTheme 为主，Glass 作为变体)，建立 `DesignTokens` 单一真相源，逐步替换硬编码值。预计工作量 8-12 小时。
