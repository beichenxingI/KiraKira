## 6. 已知技巧（关键，避免重蹈覆辙）

### 6.1 PowerShell 是唯一可靠脚本工具
- python 不可用，`head`/`tail`/bash 管道全不可用（PowerShell 不认）
- **Bash 惯用法→PowerShell 对照**：
  - `head -40` → `Select-Object -First 40`
  - `tail -3` → `Select-Object -Last 3` 或 `Get-Content -Tail 3`
  - `grep -r` → 用 `grep_files` 工具（不要用 `Select-String` 递归，慢）
  - git `stash@{0}` → PowerShell 要双引号转义：`git stash show "stash@{0}"`

### 6.2 文件编码陷阱（重要！）
项目文件编码**不统一**：
- 旧文件：多带 BOM + CRLF（如 character_list_screen.dart、regex_widgets.dart、app.dart）
- 会话新建文件：无 BOM + LF（main.dart、initialization_module.dart，因用 write_file 创建）

**陷阱**：`edit_file` 和 `apply_patch` 对 **BOM + CRLF 文件不可靠**——search 串按 LF+无BOM 匹配会失败（"Search string not found" / "hunk N failed"）。

**对策**：
- 检查编码：`$b=[IO.File]::ReadAllBytes($p); $b[0] -eq 0xEF ...`
- 对 BOM文件编辑，优先用 **PowerShell 按行数组操作**：
  ```powershell
  $path = "lib/...dart"
  $lines = Get-Content $path   # Get-Content 默认保留每行内容（去CRLF）
  # 删除行 L843-L947（1-based转0-based：索引842..946）
  $keep = $lines[0..841] + $lines[947..($lines.Count-1)]
  # 从后往前删多个块，避免行号漂移
  $keep | Set-Content $path -Encoding UTF8  # 注意Set-Content会加BOM在PS5
  ```
- 若用 `Set-Content`，**PS5 默认加 BOM**——恰好多数旧文件就这么着，符合；但 PS7 不加。以原文件 BOM 状态为准，必要时显式用 `[IO.File]::WriteAllBytes` + 手动 prepend BOM。
- 更稳：用 `[IO.File]::WriteAllText($path, $text, [Text.UTF8Encoding]::new($true))` 显式控制 BOM。

### 6.3 推荐的 BOM+CRLF 文件编辑工作流
```
1. $bytes = [IO.File]::ReadAllBytes($p)
2. $hadBom = $bytes[0..2] -eq 0xEF,0xBB,0xBF
3. $text = [Text.Encoding]::UTF8.GetString($bytes).TrimStart([char]0xFEFF) -replace "`r`n","`n"
4. 在 LF 文本上做正则/字符串操作（正则用 `n）
5. $final = $text -replace "`n","`r`n"
6. $data = [Text.Encoding]::UTF8.GetBytes($final); if($hadBom){ $data = ,(0xEF,0xBB,0xBF) + ... }
7. [IO.File]::WriteAllBytes($p, $data)
```
（本会话最后那次 `clean_character_list_screen.py` 失败后，用 PowerShell 行数组法最稳）

### 6.4 Provider 分析技巧
- 查 Provider 定义：`grep_files` pattern `final\s+\w+Provider\s*=\s*Provider`（只查纯Provider家族）
- 要查全家族（StateNotifier/Notifier/Future等）：用脚本 `scripts/generate_provider_registry.dart` 生成的 `providers_registry.dart`（含全部209个，已去重）
- 重复 provider 检测：跑 `dart run scripts/generate_provider_registry.dart`，输出打印 "Duplicate provider names" 行

### 6.5 analyze 增量与全量
- 单文件快：`flutter analyze <path>` (~2s)
- 每阶段门禁用全量：`flutter analyze 2>&1 | Out-File DiaoYan/_analyze_after_X.txt`，再 `$e = Get-Content ... | Select-String "^\s*error -"; $e.Count` 必须为0
