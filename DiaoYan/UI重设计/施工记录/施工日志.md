## 🚧 返工条目4 · Core 仪表盘 v3 布局提案(实施前先立字据)

### 第一版被否的根因
1. **切碎**:7 张功能卡 + 3 配置行 + 快捷调整 + 更多 = 十余张独立卡。不是仪表盘,是列表
2. **藏控件**:头行点 chevron 才露出滑块/开关 → 违反"进来就看到、直接能调"
3. **信息密度低**:一屏只看到 2 张卡

### v3 设计原则
- **浑然一体**:整个 Core 是**一张连续面板**,分区靠 0.5px 内部分隔线 + 区段标签(13pt 次级)
- **控件与数据同屏**:所有开关/滑块直接摆出来,零展开、零手势
- **深入入口一眼就见**:每行末 `chevron_forward`、转小字 note,不藏
- **数据可视化密集**:预算环、五条迷你胶囊采样条、状态点阵
