### 步骤 4.3：关键强制解包加保护（P0，S5）

**目标位置**（经验证）：

| 编号 | 文件 | 代码模式 | 风险 | 修复方案 |
|------|------|----------|------|----------|
| B1 | `chat_providers.dart` | `chat.characterId` 直接传给 `getCharacter` | chat 为 null | `chat?.characterId ?? ''` + 空检查 |
| B2 | `chat_providers.dart` | `groups.firstWhere(...)` 无 `orElse` | 群聊不存在抛异常 | `firstWhere(..., orElse: () => null)` |

| B4 | `llm_service.dart` | `json['key'] as Map/List` 无 try-catch | API 格式变更崩溃 | 包裹 `try-catch` 返回默认/抛业务异常 |
| B5 | `webview_chat_stage.dart` | `controller.webViewController!.evaluateJavascript` | WebView 未就绪 | `_controller?.webViewController?.evaluateJavascript(...)` |

```dart
// lib/presentation/screens/chat/chat_bridge.dart (重构)

class BridgeClient {
  final InAppWebViewController _controller;
  final Duration _timeout = const Duration(seconds: 10);
  
  BridgeClient(this._controller);
  
  /// 安全调用 JS，带超时、重试、错误上报
  Future<T?> callJS<T>(String method, dynamic params, {
    int retries = 2,
    T Function(dynamic)? parser,
  }) async {
    for (int attempt = 0; attempt <= retries; attempt++) {
      try {
        final result = await _controller
            .evaluateJavascript(
              source: 'window.__bridgeCall("$method", ${jsonEncode(params)});'
            )
            .timeout(_timeout);
        
        if (parser != null) return parser(result);
        return result as T?;
      } on TimeoutException {
        if (attempt == retries) {
          KiraLogger().error('BridgeClient', 'JS call timeout: $method');
          rethrow;
        }
        await Future.delayed(Duration(milliseconds: 200 * (attempt + 1)));
      } catch (e, stack) {
        KiraLogger().error('BridgeClient', 'JS call failed: $method', e, stack);
        if (attempt == retries) rethrow;
        await Future.delayed(Duration(milliseconds: 200 * (attempt + 1)));
      }
    }
    return null;
  }
  
  // 语义化方法
  Future<void> sendMessage(String text) => callJS('sendMessage', {'text': text});
  Future<void> updateMessages(List<ChatMessage> messages) => 
      callJS('updateMessages', {'messages': messages.map((m) => m.toJson()).toList()});
  Future<void> setGenerating(bool generating) => 
      callJS('setGenerating', {'generating': generating});
}
```

**JS 侧** (`chat_bridge_js.dart` / 内嵌 JS)：
```javascript
// 统一错误边界
window.__bridgeCall = async function(method, params) {
  try {
    const handler = window.__bridgeHandlers[method];
    if (!handler) throw new Error(`No handler for ${method}`);
    return await handler(params);
  } catch (e) {
    console.error('[Bridge] Error in', method, e);
    // 上报给 Flutter
    window.flutter_inappwebview.callHandler('onBridgeError', {
      method: method,
      error: e.message,
      stack: e.stack
    });
    throw e; // 保持 Promise reject
  }
};

// 注册处理器

  'sendMessage': (params) => { /* 实现 */ },
  'updateMessages': (params) => { /* 实现 */ },
  // ...
};
```

### 步骤 4.8：Generation Token 竞态条件重构（P1，S10）

**问题**：`_generationToken` 共享导致取消/生成错乱。

**修复方案**：每个生成任务持有独立 `CancellationToken`。

```dart
// lib/presentation/providers/chat/generation_controller.dart

class GenerationController extends ChangeNotifier {
  // 旧：int _generationToken = 0;
  // 新：
  final _activeTokens = <String, CancellationToken>{};
  
  Future<void> sendMessage(String text, List<ChatAttachment> attachments) async {
    final token = CancellationToken();
    final messageId = Uuid().v4();
    _activeTokens[messageId] = token;
    
    try {
      await _doGenerate(messageId, text, attachments, token);
    } finally {
      _activeTokens.remove(messageId);
    }
  }
  
  void cancelGeneration(String? messageId) {
    if (messageId != null) {
      _activeTokens[messageId]?.cancel();
    } else {
      // 取消所有
      for (final token in _activeTokens.values) {
        token.cancel();
      }
    }
  }
}

class CancellationToken {
  bool _cancelled = false;
  bool get isCancelled => _cancelled;
  void cancel() => _cancelled = true;
}
```
