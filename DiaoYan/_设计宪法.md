# 📜 KiraKira 设计宪法 v1

> 唯一真相源。所有页面/组件文档与本宪法冲突时,以本宪法为准。全部引用 `design_tokens.dart` 常量,禁止裸数字、禁止发明新 token(需要新增只能在 99_总体方案 提议)。

## 一、颜色(锁死,禁止页面自选)

**品牌色 —— 主次必须分明:**
- **主色 `primary` #7C7BF0(星海紫)** —— 唯一强调色。按钮、开关激活、选中态、关键图标、进度,全用它。
- **点缀 `accent` #56D4C8(青)** —— 仅用于"状态正向/数据高亮"(如 Core 仪表盘的正常状态、token 余量)。**不许拿来当第二强调色铺按钮。**
- **`secondary` #6C8FF0(蓝)** —— 降级为渐变辅助/图表第二序列,**不单独做交互色**。

> 铁律:一个界面里,可点的东西只有紫色一种信号。青色只报状态,不承担"点我"。

**深色三级(明度分层,不靠重阴影):**
```
darkBackground #0D1128  →  darkSurface #161B3A  →  darkCard #1F264A
     (最底)                    (中层)                  (浮起卡片)
分隔 darkDivider #2A3057(极细,α低)
```
**铁律:深色下用这三级明度差表达层次,卡片只加 `shadowLevel1`(α0.08 微阴影),禁止堆重阴影。**

**文字三级:**
```
textPrimary #E8EAF5(标题/正文)  textSecondary #9095B8(副)  textMuted #6A6F94(说明)
```

**待清算:`app_shell.dart` / `main_page.dart` 里的野色(0xFF1a1a2e / 0xFFa78bfa / 0xFF60a5fa)全部迁回 token,一个不留。**

## 二、圆角(单一值,禁区间)

```
卡片/底部Sheet ······ radiusXl   20
渐变卡/大对话框 ······ radiusLg   16
输入框/按钮/对话框 ··· radiusMd   12
Chip/紧凑ListTile ··· radiusSm    8
小标签细节 ·········· radiusXs    4
胶囊/底栏/搜索/FAB ··· radiusFull 30
```
**铁律:不再出现 8/11/13/16-20 这种"随便挑"。每类元素圆角唯一确定。**

## 三、间距(8pt 栅格)

```
页边距 paddingScreen 16   |   区块间距 spaceLg 24   |   元素间距 spaceMd 16
卡片内边距 paddingCard 16  |   紧凑单位 spaceSm 8    |   微调 spaceXs 4
```
**铁律:禁止 6/10/28 等非 8 倍数野值(组件库里那几处 vertical:6、fromLTRB(28…) 全部纠正)。**

## 四、字体

```
屏幕大标题 fontSize3xl 28 / w700     副标题 fontSizeLg 18 / w600
标题       fontSizeXl  20 / w600     正文   fontSizeBodyLarge 16 / w400
正文小     fontSizeBodyMedium 14      辅助说明 fontSizeXs 12 / textMuted
```
**铁律:层级靠字号+字重表达,不靠颜色乱跳(学 Notion)。**

## 五、动画(重点·你要的"手机 app 打开感")

**主力转场 —— 容器变换 Hero(命门):**
- 点角色卡 → 详情页:**卡片本身放大成页面**(Hero + 容器变换),`durationMd` 300ms + `curveStandard`。
- 设置项 → 子页:同理容器转换。
- **这是你说的"像手机软件打开那种",不是整屏推拉。**

**其余分层:**
```
微反馈(涟漪/高亮/按钮缩放0.97) ··· durationXs 100ms
快速过渡(淡入/Chip/开关) ········ durationSm 200ms + curveFade
标准(卡片入场,错峰50ms) ········ durationMd 300ms + curveDecelerate
强调(展开/大面板) ··············· durationLg 400ms
对话框 ························· durationDialog 250ms + curveSpring
```
**铁律:列表项进场错峰 50ms 淡入上移;所有可点元素必有反馈(涟漪或缩放)。**

## 六、结构铁律(破你现在"不顺眼"的根)

1. **深色靠明度分层不靠重阴影**(见§一)——你现在扁平糊在一起的主因。
2. **设置/高密度页用 iOS InsetGrouped 分组卡**:大卡共享圆角,内项无独立圆角,靠留白分组不靠碎裂分隔线。
3. **Core 界面必须可视化,禁止纯文字开关堆砌**:Hero 指标卡(环形图/进度条/大数字)+ 状态色编码(青=正常/黄=警告/红=离线),把"格子"改成"仪表盘"。
4. **搜索栏全局统一**:抽 `KiraSearchBar`,顶部吸附胶囊 filled,各页共用一套。
5. **按钮统一**:补 `KiraButton`(Filled 紫底/Outlined 紫边/Text),全 App 替换 Material 原生。**此项为中风险批量替换(30+处),宪法内单列一轮做,不与其他改动混提交。**
6. **聊天页(webview)不动**:连读都不读,只描述现状。
