**目标单例**：

```dart
// lib/core/services/lifecycle_service.dart
abstract class LifecycleAware {
  void initialize();
  void dispose();
  bool get isInitialized;
}

class LifecycleService {
  static final List<LifecycleAware> _services = [];
  
  static void register(LifecycleAware service) {
    _services.add(service);
    service.initialize();
  }
  
  static void disposeAll() {
    for (final service in _services.reversed) {
      service.dispose();
    }
    _services.clear();
  }
}

// 各单例实现 LifecycleAware
class VariablesService implements LifecycleAware {
  static final VariablesService instance = VariablesService._();
  
  @override
  void initialize() { /* 加载持久化 */ }
  
  @override
  void dispose() { 
    _stores.clear(); 
    _persistAll();
  }
  
  @override
  bool get isInitialized => true;
}
```

**在 `InitializationModule` 中注册**：

```dart
// initialization_module.dart
void _createServices() {

// main.dart - 应用退出时
// 使用 WidgetsBindingObserver 监听生命周期
class AppLifecycleObserver extends WidgetsBindingObserver {
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    if (state == AppLifecycleState.detached) {
      LifecycleService.disposeAll();
    }
  }
}
```

#### S7：`List<ChatMessage>.from()` 改增量更新

**现状**：每次生成 `List<ChatMessage>.from(state.messages)` 全量拷贝。

**优化**：使用 `built_value` 持久化列表或手工实现结构共享。

```dart
// chat_state.dart
class ActiveChatState {
  // 使用不可变列表 + 结构共享
  final List<ChatMessage> messages;
  
  ActiveChatState copyWith({
    List<ChatMessage>? messages,
    // ...
  }) {
    return ActiveChatState(
      messages: messages ?? this.messages, // 直接复用引用
      // ...
    );
  }
  
  // 追加消息：创建新列表共享旧元素
  ActiveChatState appendMessage(ChatMessage message) {
    return copyWith(messages: [...messages, message]);
  }
  
  // 更新单条消息：仅替换该索引
  ActiveChatState updateMessage(int index, ChatMessage message) {
    if (messages[index] == message) return this; // 无变化
    final newList = List<ChatMessage>.from(messages);
    newList[index] = message;
    return copyWith(messages: newList);
  }
}
```

#### S8：正则脚本预编译缓存

**现状**：`regex_service.dart` 每次消息遍历所有启用脚本，运行时编译正则。

**优化**：

```dart
// regex_service.dart
class RegexService {
  final Map<String, RegExp> _compiledCache = {};
  final Map<String, List<RegexScript>> _scriptsByPlacement = {};
  
  void _rebuildCache() {
    _compiledCache.clear();
    _scriptsByPlacement.clear();
    
    final scripts = ref.read(regexScriptListProvider).value ?? [];
    for (final script in scripts.where((s) => !s.disabled)) {
      try {
        _compiledCache[script.id] = RegExp(script.findRegex);
        for (final placement in script.placement) {
          _scriptsByPlacement.putIfAbsent(placement.name, () => []).add(script);
        }
      } catch (e) {
        KiraLogger().warning('RegexService', 'Invalid regex: ${script.id} - $e');
      }
    }
  }
  
  String apply(String input, RegexPlacement placement, {Character? character}) {
    final scripts = _scriptsByPlacement[placement.name] ?? [];
    var result = input;
    for (final script in scripts) {
      if (script.characterId != null && script.characterId != character?.id) continue;
      final regex = _compiledCache[script.id];
      if (regex != null) {
        result = result.replaceAllMapped(regex, (m) => script.replaceString);
      }
    }
    return result;
  }
}
```

**触发重建**：脚本增删改、启用/禁用时调用 `_rebuildCache()`。

### 步骤 6.6：Rust FFI 迁移评估（R1）

**评估目标**：判断 `png_parser.rs`、`charx_parser.rs` 是否可迁移至纯 Dart。

**现状分析**：

| 解析器 | 功能 | Dart 替代方案 | 可行性 |
|--------|------|---------------|--------|
| `png_parser` | 读取 PNG tEXt chunk 提取 `chara` 基64 JSON | `image` package + 手工 chunk 解析 | ✅ 高 |
| `charx_parser` | 解压 Zip 读取 `card.json` | `archive` package | ✅ 高 |

**原型验证**：

```dart
// 纯 Dart PNG 解析原型
Future<Map<String, dynamic>?> parsePngChara(Uint8List pngBytes) async {
  // 1. 验证 PNG 签名
  if (pngBytes.length < 8 || !_isPngSignature(pngBytes)) return null;
  
  // 2. 遍历 chunks
  int offset = 8;
  while (offset < pngBytes.length) {
    final length = _readUint32(pngBytes, offset);
    final type = String.fromCharCodes(pngBytes.sublist(offset + 4, offset + 8));
    offset += 8;
    
    if (type == 'tEXt') {
      final keywordEnd = pngBytes.indexOf(0, offset);
      final keyword = utf8.decode(pngBytes.sublist(offset, keywordEnd));
      if (keyword == 'chara') {
        final textData = pngBytes.sublist(keywordEnd + 1, offset + length);
        final jsonStr = base64Decode(textData);
        return jsonDecode(utf8.decode(jsonStr));
      }
    }
    
    offset += length + 4; // data + CRC
  }
  return null;
}
```

**结论模板**：


### 步骤 6.7：Live2D/WebView 原生化评估（R2-R4）

**评估维度**：

| 方案 | 技术栈 | 优势 | 劣势 | 推荐度 |
|------|--------|------|------|--------|
| 现状 | WebView + Live2D Cubism JS | 现成、特性全 | 性能差、调试难、热重载无 | 维持 |
| Flutter 原生 | Flare/Rive + 自定义渲染 | 性能好、热重载、一体化 | 需重写动画、Cubism 特性不全 | 长期 |
| 混合优化 | 保留 WebView 但提取消息列表/输入栏原生 | 渐进式、风险低 | 仍有桥接开销 | 短期 |

**建议**：

- 中期：评估 Rive 替代 Live2D，保留精灵系统（已原生）

## 3. 自动化债务检测脚本

**脚本**：`scripts/debt_detector.dart`

```dart
import 'dart:io';

void main() async {
  print('🔍 技术债务扫描开始...\n');
  
  int totalIssues = 0;
  
  // 1. TODO/FIXME 统计
  totalIssues += await _scanTodos();
  
  // 2. 硬编码颜色/圆角/间距/字号
  totalIssues += await _scanHardcodedTokens();
  
  // 3. 缺失 dispose
  totalIssues += await _scanMissingDispose();
  
  // 4. 强制解包
  totalIssues += await _scanForceUnwrap();
  
  // 5. 同步 I/O
  totalIssues += await _scanSyncIO();
  
  // 6. 文件行数过大 (>800)
  totalIssues += await _scanLargeFiles();
  
  // 6. 循环复杂度过高 (简易：函数行数 > 50)
  totalIssues += await _scanComplexFunctions();
  
  print('\n📊 扫描完成，共发现 $totalIssues 个潜在债务项');
  if (totalIssues > 0) exit(1);
}

Future<int> _scanTodos() async {
  final result = await Process.run('grep', ['-rn', 'TODO\\|FIXME\\|HACK', 'lib/', '--include=*.dart'], runInShell: true);
  final lines = result.stdout.toString().trim().split('\n').where((l) => l.isNotEmpty).toList();
  print('📝 TODO/FIXME/HACK: ${lines.length} 处');
  for (final l in lines.take(10)) print('  $l');
  if (lines.length > 10) print('  ... 及其他 ${lines.length - 10} 处');
  return lines.length;
}

Future<int> _scanHardcodedTokens() async {
  int count = 0;
  // 颜色
  count += await _grepCount(r'Color\(0x[0-9A-F]{6,8}\)', '硬编码颜色');
  // 圆角
  count += await _grepCount(r'BorderRadius\.circular\(\d+\)', '硬编码圆角');
  // 间距
  count += await _grepCount(r'EdgeInsets\.(only|symmetric|all)\([^)]*\b(10|14|18|22|26|28|30|34|38|42|46|50)\b', '非标准间距');
  // 字号
  count += await _grepCount(r'fontSize:\s*(10|11|13|15|17|18|22|24|28)\b', '非标准字号');
  return count;
}

Future<int> _scanMissingDispose() async {
  final files = await _findFilesWith('AnimationController');
  int issues = 0;
  for (final file in files) {
    final content = await File(file).readAsString();
    final controllers = RegExp(r'AnimationController\(').allMatches(content).length;
    final disposes = RegExp(r'\.dispose\(\)').allMatches(content).length;
    if (controllers > disposes) {
      print('⚠️ $file: $controllers Controller, $disposes dispose');
      issues += controllers - disposes;
    }
  }
  return issues;
}

Future<int> _scanForceUnwrap() async {
  // 简易检测
  int count = 0;
  count += await _grepCount(r'\!\s*[;,)]}]', '强制解包 !');
  count += await _grepCount(r'as\s+(Map|List|String|int|bool|double)\b', 'as 强转无保护');
  return count;
}

Future<int> _scanSyncIO() async {
  return await _grepCount(r'readAsBytesSync|readAsStringSync|writeAsBytesSync|writeAsStringSync', '同步 I/O');
}

Future<int> _scanLargeFiles() async {
  int count = 0;
  final files = await _findFilesWith('.dart');
  for (final file in files) {
    final lines = (await File(file).readAsString()).split('\n').length;
    if (lines > 800) {
      print('📄 $file: $lines 行 (>800)');
      count++;
    }
  }
  return count;
}

Future<int> _scanComplexFunctions() async {
  // 简易：函数体行数 > 50
  return 0; // 需 AST 分析，暂略
}

Future<int> _grepCount(String pattern, String label) async {
  final result = await Process.run('grep', ['-rn', pattern, 'lib/', '--include=*.dart'], runInShell: true);
  final lines = result.stdout.toString().trim().split('\n').where((l) => l.isNotEmpty).length;
  if (lines > 0) print('🔍 $label: $lines 处');
  return lines;
}

Future<List<String>> _findFilesWith(String pattern) async {
  final result = await Process.run('grep', ['-rl', pattern, 'lib/', '--include=*.dart'], runInShell: true);
  return result.stdout.toString().trim().split('\n').where((l) => l.isNotEmpty).toList();
}
```
