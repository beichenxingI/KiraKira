## 确诊

- **P1 · 真 EJS 执行点不存在**。th_renderEJS(_handleRenderEJS)只做 substituteParams 宏替换;_renderEJSInMessages 的「EJS 渲染」实为宏替换;全仓无任何 `<% %>` 模板执行代码。锚点:webview_chat_stage.dart 注释「EJS 渲染桥:接收文本,发进引擎房跑 dist 的 EJS」与实现不符。影响:条件分支(♪ 类)永远不生效——与历史现象吻合。

- **P2 · checkScript 未定义**。createEngineRoom 内 `checkScript.textContent = ...` 引用了从未声明的变量 → ReferenceError 被 catch,后果:①dist 的 substituteParams 永不挂载到 _TH;②日志「[引擎房] EJS 模块已注入」永不出现,反而打「EJS 注入失败」,误导排障;③dist 本体其实在 throw 前已注入。锚点:webview_chat_stage.dart 内唯一一处 checkScript 出现。

- **P3 · 三大钩子从不 emit**。GENERATION_AFTER_COMMANDS / CHAT_COMPLETION_SETTINGS_READY / CHARACTER_MESSAGE_RENDERED 只存在于常量表(facade tavern_events + 外层表),Dart/facade 全文无 emit 点。监听它们的脚本静默不跑。【实证:Dart 层;bundle 内部是否自产→待验证】

- **P4 · generation_started 双发**。同一轮生成在 _sendMessage(「触发 MVU initCheck(generation_started 在生成前点火)」)和 isGenerating false→true watcher 各 fire 一次 → MVU initCheck 每轮跑两次(幂等则浪费,非幂则变量双动)。chat_changed 同理双火(进入聊天外推一次 + 引擎房 300ms 自fire 一次,后者不带 msgs)。

- **P5 · 全局变量懒加载 → 覆盖丢档风险**。VariablesService.initialize 仅由 globalVariablesProvider 首次 watch 触发(variables_providers.dart GlobalVariablesNotifier._loadVariables);providers_registry 只是 export。若启动后从未打开变量设置页而 MVU/宏先写全局变量:setGlobalVariable 会把内存空表+新 key 整体存盘,覆盖 SP 里旧的全局变量存档。数据丢失级风险。

- **P6 · 遗留调试残迹**。_sendMessage 开头 print(「这是测试探针」);_serializeMessagesForMvu 开头对每条消息 debugPrint 全量 swipesData(base定位)+ 存储A dump——长聊天性能拖累且把变量内容刷进日志;同函数尾部两个空 for 循环(「for (final r in result) {}」类死代码)。

- **P7 · th_getVars 无 message 分支**。_handleGetVariables 只支持 global/chat。当前 MVU 走 facade 镜像版不受影响,但外层消息卡 iframe 若经 typeMap 调 getVariables(type:message) 会拿到 chat 层兜底?——typeMap payload 组装只有 option 直传,Dart 侧 type=message 时走「默认 chat 局部变量」分支返回错层变量。【确诊:代码路径存在;是否有实际调用方→待验证】

## 疑似

- **P8 · dist 疑似纯摆设但仍在自嗨**。无消费方(见 00 文档第3节);但其顶层初始化代码会在引擎房内执行(TavernHelper 是完整前端扩展),可能在黑箱里注册事件、抢答、抛错。需要探针确认它到底干了什么。
- **P9 · yaml 空桩**。stub 的 yaml.load 返回空对象;若 MVU bundle 不自带 yaml 而依赖宿主提供,initvar 的 YAML 解析全灭(MVU 拿到空 schema/stat_data)。与「高星卡变量初始化不生效」类现象直接相关。锚点:ejs_stub.js「[STUB!] 初始变量YAML,卡带initvar时用」。

- **P10 · getLorebookSettings 空全局书单**。facade 固定返回 selected_global_lorebooks:[] → MVU 视角全局世界书永远为空 → 全局书的 initvar/变量注入不触发。

- **P11 · replaceVariables 语义偏差**。上游语义整表替换,此处与 setVariables 同为合并(message 层反而是整份替换)。MVU 若靠 replace 清理已删 key 会残留脏数据。

- **P12 · 双份 tavern_events 表漂移**(见 X7)——已是事实性不同步,只是尚未咬到。

- **P13 · 消息级并发写无锁**。swipes 切换/编辑消息与 MVU 回写同时发生时,updateMessageSwipesData 读-改-写竞态可能丢变量(单协程事件循环下窗口小但存在)。
