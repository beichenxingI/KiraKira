# 04 · 取证建议 —— 阶段 B 探针打点建议

> 只是建议,本阶段一个探针都没加。原则:先证黑盒(bundle 行为),再验静默链,全部走现有 __thLog 通道,不动任何逻辑。

## B1(对应 P8/P1/P2,最高优先)
引擎房 load 完成后(现有错误捕手脚本之后)追加一段只读诊断 JS:
- `Object.keys` 列出 window._TH 全部 key 及 substituteParams 的 typeof;
- 尝试 `import(distBlobUrl)` 前记录 blobUrl;列出 module 导出名;
- 对比 `_TH.substituteParams === facade版?`;
- 打印 `window.chat.length / chat_metadata.variables / extension_settings.variables` 快照。
→ 一发探针同时回答:dist 导出面有什么、substituteParams 挂没挂上、Trinity 三对象里有没有真数据。顺带把 checkScript 死代码修掉的建议也在此提出(阶段 C 动手项,不是本阶段)。

## B2(对应 P3/P15)
